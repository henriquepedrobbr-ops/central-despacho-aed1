# Operação Temporal: Central de Despacho da Rede Elétrica

Trabalho Final da disciplina de **Algoritmos e Estruturas de Dados I (AED I)** — Universidade Federal de Pelotas (UFPel).

Sistema desenvolvido em linguagem C para gerenciar o cadastro de unidades consumidoras, abertura e priorização de chamados de emergência, despacho de equipes de campo e histórico de atendimentos.
